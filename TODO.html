Patch de CPUID do Intel Atom (XNU 1504 / Darwin 10.8) XNU Kernel
Aplicar patch no cpuid.c do XNU para reconhecer o Family 6, Model 28 (Pineview N450) como processador suportado sem disparar Kernel Panic de CPU não suportada.

Emulação de Instruções Faltantes & SSSE3 XNU Kernel
O Atom N450 possui SSSE3 mas não suporta SSE4.1/4.2. Tratar exceções #UD (opcode inválido) para emular chamadas SSE4 se algum binário tentar usá-las.
Arquivo: osfmk/i386/trap.c (Tratador T_INVALID_OPCODE)
